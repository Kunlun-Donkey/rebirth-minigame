# 章鱼骑自行车（动画 SVG）

## 提示词（合并版，可直接复用）

```
生成独立SVG图形：带着海盗眼罩和海盗帽子的章鱼骑自行车，并且是会动的动画SVG
硬性规则：
1. 构图：章鱼的触手抓车把、踩踏板，结构逻辑正常，无穿模
   - 两条触手分别握住车把中段和车把握套，触手尖缠绕在把手上
   - 两条触手分别踩近侧、远侧踏板；远侧触手和远侧踏板画在车架后面，近侧的画在前面，层次正确
   - 章鱼外套膜（头部）坐在车座上；其余触手在身后挥舞、飘动
2. 整体图形放在一个带 skewX(-5) 的 g 变换组内（可在外层加 translate 修正位置）
3. 增加一层 mask 蒙板，用圆形遮罩裁剪整个画面（圆心 256,256，半径 240），圆外加一圈描边
4. 轮廓描边风格：触手用"深色粗描边 + 浅色细描边"两层叠出轮廓；优先用 T 平滑贝塞尔（Q…T…）画触手；
   吸盘用虚线描边表示，不要大量单独的小圆
5. 自行车结构完整：前后 2 个轮子（带辐条），车架（上管、下管、立管、后上叉、后下叉、前叉），
   车座、车把、链轮和链条、左右曲柄和踏板，车把上装铃铛
6. 禁止外部资源，禁止图片引用，禁止 JS；动画只用 SVG 原生 SMIL（animate / animateTransform / animateMotion）
7. 尺寸：width=512，height=512，viewBox="0 0 512 512"
8. 输出只返回 SVG 代码，除注释外不带任何文字或解释；<title> 写 opus_5.5_zhangyu_ridebike，
   并保存为文件 opus_5.5_zhangyu_ridebike.svg
9. 动画要求（全部无限循环）：
   - 踩踏：两边曲柄和链轮绕中轴转（周期 1.2s）；踏板用 animateMotion 沿曲柄圆周走，始终保持水平；
     两条踩踏板的触手用 animate 改路径 d（每 45° 一帧，共 8 帧），周期和曲柄一致，触手尖始终卷在踏板上不脱开；
     左右两边相差 180°
   - 车轮：前后轮辐条旋转（0.9s），每个轮子加一根彩色辐条方便看出转动；链条用 stroke-dashoffset 滚动
   - 细节：铃铛每 3 秒左右晃一下并出现声波；眼睛每 4 秒眨一次（以眼睛中心为基准缩放）；
     海盗帽轻微晃动；身后的触手挥舞飘动；速度线闪动；地面纹理向后滚动
```

原始提示词只有第 1~8 条（没有动画、没有要求保存文件）；第 9 条和各条的细化是后续对话追加后合并进来的。
