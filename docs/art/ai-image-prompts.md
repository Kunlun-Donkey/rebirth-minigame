# AI 生图提示词（通用层 + 命格层）

> 《这一世我重生了》
> 游戏会有多个命格（小草、狗、人、猪、羊……）。为了控制美术量，素材分两层：
> - **通用层 `common/`**：所有命格共用，只画一次。UI 卡片、面板、卡框、徽记、**符号化图标**都在这一层，画面里**不出现具体的植物、动物或人物**。
> - **命格层 `destiny/<命格id>/`**：每个命格独立，只放少量场景图；最少 3 张就能上线一个新命格。
>
> **每一段提示词都是完整的，直接整段复制到生图工具即可**（即梦 / 通义万相 / 可灵 / 豆包 / Midjourney 等）。
> 表格形式的成组图标：复制模板，把【】里的内容换成表格里对应的一行。
> 生成后按文件名保存到 `D:\oled\cocos`，告诉我即可，我负责抠图、裁边、压缩、入库。

**使用建议**
1. **比例一定要在工具里单独选对**：之前几张生成成了 3:4。竖屏背景要 **9:16**，横版卡片要 **3:2**，图标要 **1:1**。
2. 先生成的图可以作为「参考图 / 风格垫图」保证统一：通用层用已有的 `event_card` 作垫图，图标组用该组第一张作垫图，命格层用该命格的 `settle_bg` 作垫图。
3. 卡框、徽记、图标用**纯白底**生成即可，我来抠透明。
4. 图里出现乱码文字，用局部重绘擦掉。

首屏图（`main_bg`、`logo_title`、`btn_*`、`panel`）放 `assets/resources/textures/`（主包），其余放 `assets/subres/textures/`（分包），两边子目录结构相同：

```
textures/
  common/
    ui/      event_card  event_card_gold  event_card_sudden  epitaph_card  ending_card  settle_panel
    frame/   frame_{common|rare|epic|legend}  badge_{talent|item|companion|skill}
    fx/      fx_breakthrough
    icon/    death_*  skill_*  item_*  talent_*
  destiny/
    <命格id>/  main_bg  settle_bg  settle_bg_ending  cover  [epitaph_card]  [stage_*]  [companion_*]
```
命格目录下有同名文件（如 `epitaph_card`）时，代码优先用命格版，否则回落到 `common/`。
