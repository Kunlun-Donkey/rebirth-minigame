# 美术需求 · 命格「一个打工人」`destiny/worker/`

> 给生图窗口用。**代码已全部接好**：同名文件放进对应目录即自动生效，缺图时用纸张底色 / 文字兜底。
> 通用层（卡框、徽记、死因/技能/道具/天赋/属性/工具栏图标）**全部复用已有素材，不用再画**。
> 风格沿用 [ai-image-prompts.md](ai-image-prompts.md)（东方幻想扁平厚涂 + 纸张颗粒），比例在工具里单独选对。

主色调：**奶油纸底 + 写字楼蓝灰 + 晚霞橙**（与荒漠赭石、土狗麦秸黄区分：更都市、更冷一点，但用晚霞橙保持温度）。
世界观：当代都市，不点真实公司、品牌、地名。写字楼群、工位、天台、夜市、地铁口、外卖电动车、出租车、城中村天台。主角是二十出头的普通年轻人：衬衫 + 工牌、双肩包，**不画具体五官细节**（扁平剪影即可，方便玩家代入）。

审核红线：不画猝死、加班倒地、跳楼等暗示；系统界面不出现真实 App 图标；海外线不画具体国家地标。

## 提示词

**main_bg**
> 竖版 9:16 手机游戏背景，东方幻想扁平厚涂风格，纸张颗粒质感。傍晚的城市，远处一排写字楼剪影，窗格亮着暖黄灯光，天空从奶油色渐变到晚霞橙。画面下方是街道和人行道，地面颜色柔和、细节少。没有人物特写，没有文字，没有品牌标志。主色奶油、蓝灰、晚霞橙。

**settle_bg**（这一世结束）
> 竖版 9:16，同风格。深夜的城市天台，深蓝夜空，零星星光，远处写字楼只剩几盏灯。画面下方中央留出一片暖色光晕（会叠墓志铭卡）。安静、略带惆怅，不悲惨。无文字。

**settle_bg_ending**（达成结局）
> 竖版 9:16，同风格。清晨日出的城市，金橙色阳光铺满楼群，天空明亮温暖。画面下方中央一个穿衬衫的年轻人背影站在天台上远望。圆满、开阔。无文字。

**cover**
> 1:1 方形图标插画，扁平厚涂。一个背双肩包、挂工牌的年轻上班族剪影站在写字楼前，背景晚霞橙。简洁、居中、无文字。

**stage_1..5**（透明背景，同一个人物逐级变化）
1. 实习牛马：抱着一摞文件、有点慌张的新人，工牌歪着。
2. 打工人：坐在工位前、表情淡定，手边一杯咖啡。
3. 觉醒者：身上浮起淡蓝色光点，衬衫袖子卷起，眼神变亮。
4. 都市高手：西装外套、自信站姿，身后有一圈金色光晕。
5. 地球球主：站在地球上方的剪影，披着晚霞色光芒，夸张但不严肃（带一点搞笑感）。
