# 命格·海洋系 —《一只皮皮虾》设计要点 v0.1

> 数值与格式以 `assets/resources/data/destinies/mantis_shrimp/` 为准；通用机制见 `01-plant-destiny.md`。
> 解锁：一只土狗任意一世长成「土狗」（`data/destinies/index.json`）。

## 一句话
你是一只差点被端上桌的皮皮虾。你有世界上最快的一拳，和十六种颜色的眼睛。
**这一世，你要一拳打出一片海。**

## 与其他命格的差异

| | 一只皮皮虾 |
|---|---|
| 生命 | 体力（每季 -1，归零 = 力竭） |
| 回复 | 打洞 ÷ 6（洞挖得好睡得香） |
| 成长货币 | 海灵 = 1 + 游速 ÷ 3 |
| 三个方向 | **上浮**（海鸥·渔网·浪尖）/ **下潜**（打洞·安全·深海龙宫）/ **随潮漂流**（码头·远海） |
| 境界 | 虾苗→皮皮虾→拳虾→虾霸→虾王→海神虾 |
| 结局 | 海神虾 / 龙宫虾帅（打跑缠住龙宫的海蛇）/ **皮皮虾我们走**（风暴里驮着阿海冲出去）/ 水族馆明星 / 珊瑚礁守护者 / 水箱之王 |

## 出生地图（每一世随机一张）

| 地图 | 权重 | 开局 | 特色 |
|---|---|---|---|
| 滩涂 | 4 | 打洞 +1 | 退潮晒干、赶海的人挖洞、阿海 |
| 珊瑚礁 | 3 | 灵性 +1 | 珊瑚缝邻居、珊瑚白化（救礁 →「珊瑚礁守护者」）、章鱼墨斗 |
| 海鲜市场 | 3 | 拳力 +1 | 开局在水箱里：老板捞虾、箱沿越狱、增氧泵管道、排水沟入海；结局「水箱之王」 |

## 三条情绪线
1. **宿敌·墨斗**（大章鱼）：吃掉一半兄弟 → 你一拳打吸盘 → 它老了被海鳗堵住，你帮它赶走海鳗（或当面亮出它的墨囊）。
2. **胖老板**（海鲜市场）：网兜捞虾 → 你打穿网兜 → 虾王回来一拳打碎水箱，满箱的虾全跑了。
3. **情感线·阿海**（渔民的孙子）：偷偷把你从网里扔回海 → 码头重逢 → 风暴里他抓着船板，你驮着他冲出去：「皮皮虾，我们走！」

## 死法 → 传承
力竭→耐力、寿终→老虾的见识、被石斑鱼吞→硬壳、被章鱼缠住→滑溜、被渔网捞走→识网、被端上了桌→倒刺尾、被海鸥叼走→沙色、被螃蟹夹住→反击拳、退潮被晒干→保湿、被大浪拍上礁石→稳如礁、**被深海压扁→深海体（Lv2 才能下海沟，第一次去必死）**、渡劫被雷劈→雷纹。

## 审核口径
- 「被端上了桌」只写墓志铭「那盘椒盐的，据说很鲜」，不写烹饪过程。
- 人类（老板、赶海人）只做捞/挖的轻度行为，结局是老板「换了行」。

## 数值基线（`npm run sim -- --destiny mantis_shrimp`，随机 AI 2000 世）
命盘全满约 88 世；61 世后结局率约 24%。「皮皮虾我们走」是隐藏结局（需滩涂/市场出生 + 阿海线 + 虾王 + 海神虾），随机 AI 很少达成。
