# 命格·动物系 —《一只土狗》设计要点 v0.1

> 数值与格式以 `assets/resources/data/destinies/local_dog/` 为准；通用机制见 `01-plant-destiny.md`。
> 解锁：荒漠一株草任意一世突破为「小草」（`data/destinies/index.json`）。

## 一句话
你是村口柴堆里生下的土狗。被地主家的狼狗抢食、被狗贩子盯上、被养你的小姑娘留在了村里。
**每一次死去，你都记得是谁。这一世，你要一口一口咬回来。**

## 与「草」的差异（同一引擎，不同 rules）

| | 荒漠一株草 | 一只土狗 |
|---|---|---|
| 生命 | 水分（每季 -1） | 体力（每季 -1，归零 = 饿死） |
| 回复 | 根系 ÷ 8（扎根吸水） | 忠义 ÷ 6（有人喂饭） |
| 成长货币 | 灵气 = 1 + 茎叶 ÷ 3 | 妖气 = 1 + 脚力 ÷ 3（山里吸月华） |
| 三个方向 | 向上 / 向下 / 向旁 | **进山**（修炼·危险）/ **守村**（人情·安全）/ **流浪**（剧情·奇遇） |
| 境界 | 草籽→嫩芽→小草→灵草→草精→树妖 | 土狗崽→土狗→灵犬→犬妖→妖王→天狗 |
| 结局 | 荒漠树妖 / 绿洲之主 | **天狗·仙君** / **护村神犬**（救下全村） |

## 三条情绪线（爽点）

1. **宿敌·黑虎**（地主家的大狼狗）：抢你的食 → 你长牙后咬回去 → 黑虎被地主嫌老赶出门，饿得皮包骨来求你，你分它半个馒头（或当着它的面吃完）。
2. **宿敌·刘拐子**（狗贩子）：第一次见面把你拴上车（死法「被狗贩子带走」）→ 传承「警觉」后你能躲开 → 妖王阶段一口咬开他满车的笼子，放走所有的狗。
3. **情感线·小翠**（小时候喂你的小姑娘，全家进城把你留在村里）：流浪到京城时再遇见她，她已经长大，蹲下来叫出你小时候的名字。

## 死法 → 传承（死得有因果）
饿死→耐饿、寿终→老狗的智慧、被赶出村→记仇、被狗贩子带走→警觉、被狼群围住→狼性、踩进兽夹→机灵、误食毒饵→百毒不侵、冻死雪夜→厚毛、**古墓阴气→阴阳眼（Lv2 才能进古墓，第一次去必死）**、渡劫被雷劈→雷纹、被道士收进葫芦→敛息、被黄鼠狼骗了→识人。

## 审核口径
- 不写虐狗细节、不出现「狗肉」等字眼；死亡用「被带走」「没能回来」等温和表达。
- 人类反派只做「欺负 / 抓狗」的轻度恶意，结局是被惩戒而非被伤害致死。

## 数值基线（`npm run sim -- --destiny local_dog`，随机 AI 2000 世）

| 境界 | 条件 | 寿元 |
|---|---|---|
| 土狗 | season>=2 | 14 |
| 灵犬 | 妖气>=8 | 18 |
| 犬妖 | 妖气>=30 & 灵性>=3 | 26 |
| 妖王 | 妖气>=100 & (牙口/脚力/忠义 任一>=8) | 34 |
| 天狗 | 妖气>=400 & 牙口>=14 & 脚力>=14 & 灵性>=10 | 99 |

- 首次结局约第 56 世，61 世之后结局率约 13%（荒漠一株草约 11%），后期主要死因为寿终，说明瓶颈在「一世内能否攒够」。
- 解锁：荒漠一株草任意一世突破为「小草」（`index.json` → `unlock.bestStage`）。
- 护村神犬结局：祠堂「山匪」或古墓「僵尸」事件中救下村子（`flag:village_saved`），再突破为天狗。
