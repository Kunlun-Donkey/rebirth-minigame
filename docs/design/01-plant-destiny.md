# 命格·植物系 —《荒漠一株草》设计文档 v0.1

> 游戏：《我重生了，这一世我将拿回属于我的一切》
> 本文档是植物系命格的**单一事实源**。剧本数据格式见 §8，写剧本前必读。

---

## 0. 一句话

你是荒漠里的一颗草籽。每一次选择「向上 / 向下 / 向旁」都会把你带向不同的命运——
大概率你会死：渴死、被骆驼吃、被岩浆烤成草干。
**但每一次死亡都会刻进种子里**：根更深了、皮更厚了、你记得哪里有岩浆了。
千百次轮回之后，这片荒漠会长出一棵贯通天地的**世界树**。

参考与差异化：
- 《人生重开模拟器》：天赋抽取 + 属性 + 条件触发事件 → 我们借鉴其「极简系统撑海量内容」与「可截图分享的文字人生」
- 植物流网文（《从一株草开始进化》等）：草 → 世界树的成长爽感、建木血脉、灵气复苏
- Roguelite 局外成长（Hades / 死亡细胞）：**死亡即进度**，局外成长需边际递减
- 差异点：**玩家主动选方向（探索感）** + **死法决定传承（因果感）** + **前世记忆标注选项（重生题材落地）**

## 1. 双层循环

```
┌──────────────── 局外：轮回之种 ────────────────┐
│ 抽池：天赋 3选1 · 道具 3选1 · 伴生物 3选1        │
│ 携带：上一世封存的种子遗物（1格，可扩）           │
└──────────────┬─────────────────────────────────┘
               ▼
┌──────────────── 局内：这一世 ──────────────────┐
│ 每回合（= 一季）：                               │
│   1. 选方向：⬆向上生长 / ⬇向下扎根 / ↔向旁蔓延    │
│      （特殊回合出现第4个选项：开花/休眠/化形…）     │
│   2. 按方向+当前层+属性 抽取事件                   │
│   3. 事件文本 + 2~3个选项 → 结果（属性/道具/死亡）  │
│   4. 季末结算：水分消耗、灵气积累、境界突破检查      │
└──────────────┬─────────────────────────────────┘
               ▼ 死亡 / 结局
┌──────────────── 轮回结算 ──────────────────────┐
│ 墓志铭卡（可分享）→ 死法传承 → 轮回点 → 封存1件遗物 │
│ → 图鉴更新 → 再次重生                           │
└────────────────────────────────────────────────┘
```

单局时长目标：前 5 世 **1~3 分钟**（快死快学），中期 5~10 分钟，冲世界树 15~20 分钟。

## 2. 属性

| 属性 | 含义 | 主要来源 | 作用 |
|---|---|---|---|
| 💧 水分 | **生命值**，每季 -1（基础消耗） | 向下找水、露水、下雨 | 归零 = 渴死 |
| 🌿 根系 | 向下能力 | 向下事件、蚯蚓 | 向下探索深度门槛、抗沙暴、吸水效率 |
| 🍃 茎叶 | 向上能力 | 向上事件、阳光 | 向上高度门槛、光合产灵气 |
| 🛡 韧性 | 抗性 | 灾难幸存、传承 | 降低伤害、抵抗被吃 |
| ✨ 灵性 | 悟性/运气 | 奇遇、遗迹 | 奇遇概率、解锁对话/觉醒选项 |
| 🔆 灵气 | **成长货币** | 光合、奇遇、吞噬 | 达阈值触发境界突破 |

另有 **位置坐标**：`高度`（向上层数）、`深度`（向下层数）、`广度`（向旁区域）。

**季末自动结算**（数值见 `destiny.json` 的 `settings`）：
- 水分：`- 1（基础消耗） + floor(根系 / 8)（根系吸水）`
- 灵气（境界≥1）：`1 + floor(茎叶 / 3)`（光合）

由此三个方向定位清晰：**向下 = 水与安全**，**向上 = 灵气与成长**，**向旁 = 灵性与剧情**。

> 本文档的数值均为设计初稿；**实际数值以 `assets/resources/data/destinies/desert_grass/` 下的数据为准**，调整后用 `npm run sim` 观察分布。

## 3. 境界（成长阶段）

| 阶段 | 突破条件（草案） | 解锁 | 突破演出旁白示例 |
|---|---|---|---|
| 0 草籽 | — | 只能向下/向上 | — |
| 1 嫩芽 | 存活 2 季 | 向旁蔓延 | 「你破土而出。荒漠没有在意。」 |
| 2 小草 | 灵气 10 | 开花选项 | 「一只路过的甲虫看了你一眼。这是你第一次被看见。」 |
| 3 灵草 | 灵气 40 + 灵性 3 | 与动物对话 | 「沙漠里的风，开始绕着你走。」 |
| 4 草精 | 灵气 120 + 任一属性 10 | 吞噬、操控藤蔓 | 「骆驼们开始做噩梦。」 |
| 5 树妖 | 灵气 300 + 根系 15 + 茎叶 15 | 化形、建立绿洲 | 「荒漠第一次有了影子。」 |
| 6 古树 | 灵气 800 + 绿洲已建立 | 庇护生灵、信徒 | 「商队开始绕路来拜你。」 |

## 5. 开局三池

开局从三个池各随机 3 个、玩家各选 1 个。稀有度：⚪普通 60% / 🔵稀有 28% / 🟣史诗 10% / 🟠传说 2%。
局外解锁会把新词条加入池子（初始池小，越玩越丰富）。

### 5.1 天赋池（示例，MVP 目标 30 个）
| 稀有 | 天赋 | 效果 |
|---|---|---|
| ⚪ | 耐旱 | 水分基础消耗 -1，每 3 季才消耗一次 |
| ⚪ | 深根 | 根系 +3 |
| ⚪ | 向阳而生 | 茎叶 +3 |
| ⚪ | 苦涩 | 动物吃你的概率 -50% |
| 🔵 | 话痨 | 灵草前即可与动物对话（解锁对话选项） |
| 🔵 | 倒霉蛋（负面） | 坏事件概率 +30%，但轮回点 ×1.5 |
| 🔵 | 直觉 | 每个事件有 30% 概率显示一个选项的结果预告 |
| 🟣 | 不死草 | 本局第一次死亡时原地复活（水分回满） |
| 🟣 | 建木血脉 | 灵气获取 ×2，突破时额外 +1 全属性 |
| 🟣 | 前世今生 | 前世记忆标注范围扩大到「上上世」 |
| 🟠 | 天命之草 | 所有门槛 -30%，奇遇概率 ×3 |
| 🟠 | 我即荒漠 | 沙暴不再伤害你，而是为你所用 |

### 5.2 道具池（示例，MVP 目标 20 个）
| 稀有 | 道具 | 效果 |
|---|---|---|
| ⚪ | 一滴露水 | 使用：水分 +3 |
| ⚪ | 骆驼粪 | 使用：本季所有属性收益 ×2（「味道很冲，但很补」） |
| ⚪ | 半块甲虫壳 | 抵挡一次伤害 |
| 🔵 | 生锈的指南针 | 选方向前可预览三个方向的事件标题 |
| 🔵 | 神秘陶片 | 沉没遗迹事件必出隐藏选项 |
| 🟣 | 古代种壳 | 死亡时可多封存一件遗物 |
| 🟣 | 骆驼的一颗牙 | 宿敌「老刀」线专属：可触发复仇事件 |
| 🟠 | 建木残片 | 直接解锁 D6 地脉门槛 |

### 5.3 伴生物池（示例，MVP 目标 8 个）
伴生物是**会成长、有小剧情线**的同伴，提供情感锚点（参考：网文里的灵宠/器灵）。

| 伴生物 | 能力 | 成长线 |
|---|---|---|
| 屎壳郎「老粪」 | 每 3 季推来一颗粪球（肥料） | 粪球越推越大 → 最终推来一颗陨石 |
| 蚯蚓「小直」 | 向下事件门槛 -1 | 陪你钻到熔岩层前会犹豫，可选择让它离开（感情戏） |
| 迷路的蜜蜂 | 解锁开花与授粉 | 带来蜂群 → 绿洲之后成为蜂后 |
| 沙漠狐幼崽 | 驱赶食草动物 | 长大后成为守护你的灵狐（树妖阶段可化形） |
| 共生真菌 | 菌根网络：每季获得一条情报 | 遍布整片荒漠 → 「荒漠的耳朵」 |
| 小蜥蜴 | 驱虫 | ⚠ 有概率在你最弱时把你吃掉（高风险高回报） |

## 6. 死亡与传承（核心机制）

### 6.1 死法 → 传承
**每种死法给一个对应的永久特性**，让「死得有意义、有因果」。特性多级、边际递减（Lv1~5，每级效果逐渐减小，避免数值爆炸）。

| 死法 | 墓志铭示例 | 传承特性 | 解锁 |
|---|---|---|---|
| 渴死 | 「享年 4 季，死于对水的思念」 | 储水细胞（水分上限 +2） | — |
| 被骆驼吃 | 「成为了骆驼的一顿早饭」 | 苦涩汁液（被吃概率 -15%） | 宿敌「老刀」登场 |
| 沙暴连根拔起 | 「第一次飞翔，也是最后一次」 | 抓地根（韧性 +1） | 风沙层「顺风」选项 |
| 被岩浆烤熟 | 「在地下 137 米成为了草干」 | 耐火根（**D5 熔岩层门槛**） | 熔岩层可通行 |
| 被雷劈 | 「死得很亮」 | 雷纹（雷云层伤害 -） | Lv3 解锁雷灵根 |
| 遗迹诅咒 | 「被三千年前的人诅咒了」 | 古语（看懂碑文） | 遗迹隐藏剧情 |
| 被人类拔走 | 「被做成了一碗草药」 | 警觉（人类事件可躲避） | 盗伐者宿敌线 |
| 自然老死 | 「平平淡淡才是真」 | 轮回点 +50% | — |

**关键设计**：部分区域「第一次去必死」，死过才有通行证——这正是用户提出的「向下发现岩浆死了，下次就能扎根更好」。

### 6.2 带出遗物
死亡时，从本局发现的道具中选 **1 件封存进种子**（「古代种壳」等可扩格）。下一世开局自带。

### 6.3 前世记忆（重生题材的落地）
玩家在前世做过的选项，下一世会标注结果：
```
  [向下扎根]
  ─────────────────────────
  > 继续向下         〔前世：你在这里被岩浆烤熟了〕
  > 绕开那股热气
  > 用耐火根硬闯     〔传承 · 耐火根 Lv2〕✨
```
这样「重生」不只是标题，而是玩家能感受到的金手指：**我知道未来，这一世我要拿回一切。**

### 6.4 轮回点（局外货币）
来源：存活季数、最大深度/高度、发现数、境界、首次死法；倍率：天赋/天命、命盘·福缘、今日首世 +50%、看视频翻倍。
用途：**命盘**（§6.4.2）。

**重生次数不设上限**（2026-11-02 定）：一局只有几分钟，"再来一世"是核心冲动；仅靠激励视频变现，局数越多广告曝光越多，体力/限次等于限收入。长期目标靠命盘、图鉴、结局、后续里程碑与新命格解锁提供。

### 6.4.2 命盘（局外永久升级，按命格独立）
数据在 `destiny.json` 的 `upgrades`，类型说明见 `core/types.ts` 的 `UpgradeKind`。

| 命盘 | 效果 | 价格 |
|---|---|---|
| 固本 | 开局水分上限 +1 | 120 / 360 / 900 |
| 灵根 | 开局灵气 +4 | 150 / 450 / 1100 |
| 福缘 | 轮回点 +10% | 250 / 750 / 1800 |
| 天机 | 每次开局免费「天机重演」+1（看视频那次另算） | 300 / 1200 |
| 续命 | 看视频逆天改命时，水分回满、韧性 +2 | 500 |
| 藏宝 | 遗物封存格 +1 | 1500 |
| 慧眼 | 开局三池 3 选 1 → 4 选 1 | 2000 |

节奏（`npm run sim`，随机 AI、每世买最便宜的）：不看广告约 **80 世**全满，每局看广告约 **40 世**；全满后结局率不变（≈11%），不破坏数值。

**与广告的关系（硬约束）**：命盘**只放大广告收益，不替代广告**——不提供免费复活、免费窥探、免费翻倍。
- 轮回点有了用处 → 「双倍轮回点」变得有价值；
- 续命让「逆天改命」复活更值；越强的一世死掉越心疼，复活广告转化越高；
- 天机的免费次数用完后，看视频重演仍可用。

### 6.4.3 每日天命
数据在 `destiny.json` 的 `fates`。每天（玩家本地日期）按日期哈希确定一个天命，**同一天所有玩家相同**（方便讨论/分享），当天所有轮回生效；可**看视频换一次**（随机换成另一个）。
今日第一世结算轮回点 +50%（回流动力，不限制后续游玩）。

### 6.4.1 轮回结算页（每次死亡/结局后）
数据由引擎 `settle()` 统一产出（`SettleResult`），终端试玩与 Cocos UI 共用：
1. **墓志铭卡**：第 N 世 · 死因 ·「享年 N 季，……」· 境界 ·【首次】标记（分享图素材）
2. **这一世**：三方向最远层、最终属性、发现的道具、本世领悟的技能、生平大事（含突破/抵达/复活）
3. **轮回收获**：传承（等级/说明）、死亡领悟的技能、轮回点逐项明细与累计
4. **图鉴进度**：死法 / 技能 / 道具 / 结局 / 事件
5. **下一世的目标**：本世遇到但被条件锁住的选项（最多 3 条）；因本次传承/技能已满足的标「下一世可选！」，属性类已满足的自动剔除，隐藏条件不剧透
6. **操作**：【看广告】轮回点翻倍 → 封存遗物 → 再次重生

### 6.5 技能（领悟 → 图鉴 → 携带 → 与事件交互）

**领悟途径（三种，解锁永久写入技能图鉴；局内领悟的立即可用）**
| 途径 | 配置位置 | 例 |
|---|---|---|
| 死亡 | `destiny.json` 死法的 `skills: [{id, chance, require}]`（传承结算后判定） | 渴死 50% 领悟「假死休眠」；带着耐火根 Lv2 被烤熟 50% 领悟「熔岩行走」 |
| 做出选择 | 事件效果 `"skill": "id"` | 和别的草结盟 → 「根网」；远眺荒漠尽头 → 「天眼」；吞下万年种子 → 「吞噬」 |
| 境界突破 | 境界的 `skillPool`（优先抽未解锁的） | 嫩芽：深扎/光合爆发；灵草：草木皆兵/兽语；草精：藤缚/吞噬 |

**携带**：开局最多 `skillSlots`（=3）个；已解锁超过上限时开局自选。

**三类技能**
| 类型 | 使用时机 | 例 |
|---|---|---|
| 方向技能 `use: direction` | 选方向时施展，结算效果 | 深扎、光合爆发、假死休眠、根网、引雷 |
| 事件技能 `use: event` | 事件中施展：`boost` 加成功率 / `reveal` 看穿 / `skip` 化解（门槛事件不可化解） | 草木皆兵、天眼、藤缚 |
| 交互技能（无 use） | 只在特定事件里以专属选项出现（`showIf: skill:x` + `useSkill`） | 装死、毒刺、风中之舞、兽语、拟态、吞噬、熔岩行走 |

所有技能按季冷却。部分方向/事件技能同时也有事件专属用法（藤缚捆老刀、以雷引雷）。

**和爽点的结合**：死法 → 传承 → 技能，三层因果。「前世被蝎子剪断根」→ 传承「尖刺」→ 用尖刺反制蝎子领悟「毒刺」→ 之后骆驼、蝗虫、老刀统统被毒刺伺候。

## 7. 爽点设计清单

| 爽点类型 | 实现 | 例 |
|---|---|---|
| 宿敌打脸 | 骆驼「老刀」吃了你 → 后续世代逐步复仇 | 第1世被吃；第N世你长刺扎它嘴；树妖阶段它跪在你树荫下乘凉求水 |
| 前世今生对照 | 事件文本用「前世…这一世…」句式 | 「前世，这阵沙暴把你连根拔起。这一世，你的根比沙暴更深。」 |
| 突破演出 | 全屏大字 + 震屏 + 旁白吐槽 | 「天道：？」 |
| 反差奇遇 | 金色稀有事件，截图素材 | 「一个迷路的仙人把剑插在你旁边，忘了拔走。」 |
| 墓志铭分享卡 | 每一世结束生成一张卡 | 「第7世 · 在地下137米被岩浆烤成了草干 · 享年3季」 |
| 图鉴收集 | 死法图鉴 / 发现图鉴 / 结局图鉴 | 「已收集死法 9/24」 |

旁白语气：**冷幽默 + 吐槽 + 关键时刻热血**。参考人生重开模拟器的「离谱又真实」，避免 AI 腔（写完用 story-deslop skill 过一遍）。

## 8. 剧本数据格式（草案，实现时以代码中的类型定义为准）

```jsonc
// data/destinies/desert_grass/events/down_d3.json
{
  "id": "d3_river_shell",
  "dir": "down",              // up | down | side | any
  "layer": ["D3"],            // 出现层

  "text": "你的根碰到了一块硬东西。是一只河蚌的化石——这里曾经是一条河。",
  "choices": [
    {
      "text": "缠住它，吸收里面的灵气",
      "effect": { "灵气": 8, "flag": "got_shell" },
```

效果：属性增减、`flag`、`item`、`death:<死法id>`、`next:<事件id>`、`stage_up`。

数据文件：`stages.json`、`layers.json`、`talents.json`、`items.json`、`companions.json`、`deaths.json`、`endings.json`、`events/*.json`。
所有数据由 Linux 端校验脚本检查：死链、不可达事件、未定义 id、条件语法错误。

## 11. 已定决策（2026-11-02）

1. **回合结构**：每季 80% 让玩家选方向，20% 直接触发突发事件（沙暴来袭等），制造紧张感。
2. **不做固定新手剧本**：剧本全随机，保证新鲜感。「死亡即成长」靠机制自然教会：每一种死法都必给传承，前几世的死亡结算页重点展示「你获得了 XX」。
3. **局外货币**：**轮回点全局共用**（新命格不从零开始）；**传承特性、图鉴按命格独立**（耐火根只对植物有意义）。命格之间通过彩蛋事件互相联动。
