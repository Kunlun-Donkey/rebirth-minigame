## 一句话
你是一条谁见了都说丑的小鳄鱼。冷了要晒、饿了要等、哭了没人信。
**这一世，你要从烂泥里，长成一条龙。**（鼍，古书里就是龙的一种。）

## 与其他命格的差异

| | 一条鳄鱼 |
|---|---|
| 生命 | 体温（每季 -1，归零 = 冻僵；冷血动物，得晒） |
| 回复 | 晒背 ÷ 6（越会晒越暖） |
| 成长货币 | 龙气 = 1 + 潜水 ÷ 3 |
| 三个方向 | **上岸**（晒背·人·雷）/ **潜水**（淤泥·沉船·龙渊，龙气多）/ **顺流**（河湾宿敌·城边·入海口，剧情多） |
| 境界 | 鳄蛋→小鳄鱼→河鳄→鳄霸→鳄王→鼍龙 |
| 结局 | 鼍龙化龙 / 河神（堵住洪水救下村子）/ 河湾霸主（打败独眼）/ 牙签鸟的老朋友（为叽叽留下）/ 下水道之王 / 网红鳄鱼 |

## 四条情绪线
1. **宿敌·独眼**（河湾老鳄王）：顶散你一窝兄弟 → 霸占晒背石 → 泥里伏击 → 你回河湾挑战，把它从石头上掀下来 → 它老了被渔网缠住，你咬断网 → 结局「河湾霸主」，它晚年趴在你旁边晒太阳。
2. **羁绊·叽叽**（牙签鸟）：落在鼻尖看牙 → 钻进嘴里剔牙、你忍着不合嘴 → 鹞子追它，你张嘴让它躲进来 → 带一窝小鸟来 → 它老了落在你鼻尖 → 结局「牙签鸟的老朋友」（放弃化龙）。
3. **守护·村子**：晒谷场被赶 → 抽旱烟的老头讲古（五十年前也有条鳄鱼堵过堤）→ 洪水来了你横在缺口上 → 化龙时分支「河神」。
4. **下水道·豆豆**：被冲进马桶 → 老鼠帮 → 手电光里豆豆认出了「小绿」→ 他退休那天喊你 → 结局「下水道之王」。

另有「网红鳄鱼」另类结局：公园湖被拍 → 上新闻 → 学会对镜头张嘴。彩蛋：村里的大黄狗（土狗命格）、入海口打拳的皮皮虾。

## 死法 → 传承
冻僵→蓄热、寿终→老鳄的耐心、被独眼撞翻→铁头、被水牛踩了→扁身、被偷猎的人带走→识人、旱季河干了→深窝、被鹰叼走→泥色、被鱼钩钩住→吐钩、被冲进污水处理厂→认路、**冻在了龙渊→寒鳞（Lv2 才能下龙渊，第一次去必死）**、被洪水冲走→稳如堤、渡劫被雷劈→雷纹。

## 技能
- 方向：晒背、冬眠、换牙（鳄鱼一辈子都在换牙）、引雷
- 事件：浮眼（只露眼睛看清一切）、沉底（化解）、猛扑（+30%）
- 交互：翻江（翻滚，对付大鱼/宿敌/石门）、鳄鱼的眼泪（骗过小孩、偷猎者、老鼠、大黄）、搅泥（浑水里谁也看不见谁）

## 审核口径
- 鳄鱼吃东西只写「一口吞了」「吃饱了」，不写撕咬过程；偷猎只写「绳套」「笼子」「被带走」，不出现皮制品。
- 死亡点到为止（「车开走了，河还在流」）。
