# 命格·昆虫系 —《一条毛毛虫》设计要点 v0.1

> 数值与格式以 `assets/resources/data/destinies/caterpillar/` 为准；通用机制见 `01-plant-destiny.md`，随机出生地图见 §出生地图。
> 解锁：荒漠一株草任意一世破土为「嫩芽」（`data/destinies/index.json`）。

## 一句话
你是一条谁见了都想捏死的毛毛虫。喜鹊吃了你一半兄弟姐妹，老太太天天翻叶子捉你。
**这一世，你要飞起来，让他们抬头看你。**

## 与其他命格的差异

| | 一条毛毛虫 |
|---|---|
| 生命 | 饱腹（每季 -1，归零 = 饿瘪了） |
| 回复 | 胃口 ÷ 6（能吃是福） |
| 成长货币 | 蜕变 = 1 + 攀爬 ÷ 3（往高处爬晒天光） |
| 三个方向 | **往高处爬**（修炼·鸟多）/ **埋头啃叶**（吃饱·安全）/ **爬去别处**（剧情·奇遇） |
| 境界 | 虫卵→毛毛虫→大肥虫→茧中仙→灵蝶→蝶仙 |
| 结局 | 蝶仙 / 蝴蝶谷之主（救下暴雨里的蝴蝶谷）/ 蝴蝶效应（树顶扇一下翅膀）/ 小雨的蝴蝶 / 地下歌王 / 菜园一霸 |

## 三条情绪线（爽点）
1. **宿敌·花胸**（胸口白斑的喜鹊）：出生时吃掉一半兄弟姐妹 → 你竖毛扎它嘴 → 化蝶后它老了，你撒它一脸鳞粉捡走尾羽（或飞走：「不是原谅，是它不配」）。
2. **老太太**（菜园）：天天翻叶子捉虫 → 你化成大蝴蝶落在白菜上冲她点头 →「菜园一霸」。
3. **情感线·小雨**（公园/菜园的小姑娘）：把你养在玻璃罐里 → 你在罐里结茧，破茧时落在她发梢，她把发带系在罐子上 → 长大后在植物园门口等你 →「小雨的蝴蝶」。

## 死法 → 传承
饿瘪→大胃袋、寿终→老虫的见识、被鸟叼走→保护色、被鸡啄/撞螳螂→毒毛、被农药熏晕→厚皮、被捏走→警觉、被暴雨冲下树→抓地足、被蚂蚁搬走→蚁族之约、茧里睡过头→耐心、渡劫被雷劈→雷纹、**被地下歌声迷住→塞耳（Lv2 才能进树根下，第一次去必死）**。

## 审核口径
- 死亡点到为止：被叼走、被捏走、睡过头，不写细节。农药只写「白雾」「薄荷味」。
- 小孩只是好奇、拿树枝戳，不写虐虫。
