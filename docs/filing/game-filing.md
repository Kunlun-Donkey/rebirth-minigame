## 一、游戏简介

**短版（约 60 字）**
> 一款文字选择类单机小游戏。玩家扮演荒漠中的一颗草籽，通过一次次生长抉择与轮回重生，从小草逐步成长为参天古树。

**完整版**
> 《我重生了，这一世我将拿回属于我的一切》是一款以文字交互为主的轻量单机小游戏，采用"轮回重生"题材。首个篇章《荒漠一株草》中，玩家扮演荒漠里的一颗草籽，每一季选择向上生长、向下扎根或向旁蔓延，在随机事件中做出选择，应对干旱、沙暴、动物啃食等自然挑战。每一世结束后，玩家会获得传承与经验，带着"前世记忆"重新开始，逐步成长为嫩芽、小草、灵草，直至荒漠中的大树。游戏画风温和、文字诙谐，单局时长 1~10 分钟，适合碎片时间游玩。

---

## 二、主界面风格

**短版**
> 竖屏 2D，东方幻想风格的扁平厚涂插画，暖沙色调（赭石、土黄为主），纸张颗粒质感。界面以文字卡片为主，风格简洁、温和、略带幽默。

**完整版**
> 游戏采用竖屏 2D 画面，美术为东方幻想风格的扁平厚涂插画，以荒漠的赭石、土黄等暖沙色为主色调，点缀嫩绿色表现植物生命力，整体带有细腻的纸张颗粒质感。主界面以羊皮纸 / 沙色纸张质感的文字卡片为核心：上方显示当前境界、季节与属性（水分、根系、茎叶、韧性、灵性、灵气），中部为事件文字卡，下方为选项按钮。整体氛围宁静、温和，文字风格轻松幽默，无血腥、暴力、恐怖或低俗内容。

## 三、核心玩法

**短版**
> 每回合（一季）选择"向上 / 向下 / 向旁"三个方向之一，触发随机文字事件并做出选择，影响属性与命运。死亡后进入轮回，获得永久传承，下一世更强，逐步成长为大树。

**完整版**
> 1. **开局选择**：每一世开始时，从天赋、道具、伙伴（伴生物）三个卡池中各随机出 3 张卡，玩家各选 1 张。
> 2. **方向抉择**：每回合代表一季，玩家选择"向上生长 / 向下扎根 / 向旁蔓延"，不同方向对应不同的地层与区域（如湿沙层、古河床、风沙层、沙丘背面），可获得水分、灵气或剧情线索。
> 3. **事件选择**：根据方向和当前属性随机触发文字事件，每个事件提供 2~3 个选项，选择结果会改变属性、获得道具或技能，也可能导致这一世结束。
> 4. **成长突破**：积累"灵气"达到条件后完成境界突破（草籽 → 嫩芽 → 小草 → 灵草 → 草精 → 树妖），解锁新的选项与区域。
> 5. **轮回传承**：每一世结束时，根据本世经历获得永久"传承特性"和"轮回点"，并可封存一件道具带入下一世。玩家前世做过的选择会在下一世以"前世记忆"的形式标注提示，帮助玩家做出更好的决策。

## 四、系统功能

**短版**
> 开局抽卡（天赋/道具/伙伴）、方向探索、文字事件、属性与境界成长、技能系统、轮回传承、图鉴收集、墓志铭分享卡、本地存档、激励视频广告（自愿观看）。

**完整版（逐项）**

| 系统 | 说明 |
|---|---|
| 开局抽卡 | 天赋、道具、伙伴三个卡池各 3 选 1，卡牌分普通 / 稀有 / 史诗 / 传说四个品质，均为游戏内随机，**不涉及付费抽奖** |
| 方向探索 | 向上 / 向下 / 向旁三个方向，共 12 个地层与区域，满足属性条件后逐层解锁 |
| 文字事件 | 随机事件 + 选项分支，含普通事件、稀有奇遇、突发事件（沙暴、干旱等） |
| 属性系统 | 水分（生命值）、根系、茎叶、韧性、灵性、灵气六项属性 |
| 境界成长 | 6 个成长阶段，突破时有全屏演出与旁白 |
| 技能系统 | 通过事件、突破或轮回领悟技能，开局可携带 3 个，按季冷却 |
| 轮回传承 | 不同的结局方式获得对应的永久特性；可封存 1 件道具带入下一世；前世选择记忆提示 |
| 图鉴收集 | 结局图鉴、技能图鉴、道具图鉴、事件图鉴 |
| 结算与分享 | 每一世结束生成"墓志铭卡"，展示本世经历，可截图分享给好友 |
| 存档 | 使用微信本地存储保存进度，不收集用户个人信息 |
| 广告 | 仅激励视频广告，玩家**自愿**观看后获得便利（如轮回点翻倍、刷新一次卡池），不看广告也可完整体验游戏 |
| 付费 | 无任何充值或内购 |
| 联网 | 单机游戏，无多人互动、无聊天、无用户生成内容 |

## 六、填写口径提示

- 文案中统一用「这一世结束 / 轮回」代替「死亡」，用「伙伴」代替「伴生物」，审核更友好。
- 「抽卡」相关一律注明 **游戏内随机、免费、无付费抽奖**。
- 题材标签可选：休闲 / 文字 / 模拟养成 / 益智。建议不要选「角色扮演 / 修仙」类分类（游戏内虽有「灵气」「境界」，但主体是植物成长）；具体分类以后台选项为准。
